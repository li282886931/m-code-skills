# Mcd Survey Rewards — 麦当劳评价官

## Overview

麦当劳每笔订单消费后可完成满意度问卷，完成即获奖励优惠券。但大多数用户不知道有这个福利，或者忘了评价。本技能帮用户发现"待评价"订单、完成评价获取奖励券、查询已获奖励券的核销状态，确保每一张评价奖励券都不被浪费。

## Core Capabilities

### 1. 待评价订单发现

调用 `order-list` 获取历史订单列表，逐条调用 `query-survey-coupon` 查询每笔订单的满意度问卷状态：

- **可评价**：订单已完成消费但未填写问卷 → 标记为"待评价，可获奖励"
- **已评价未核销**：问卷已填但奖励券尚未使用 → 提醒使用
- **已核销**：奖励券已使用 → 标记完成
- **已过期**：超时未评价 → 标记遗憾

展示格式：
```
📋 待评价订单（X笔可获奖励）

1. [可评价] 巨无霸三件套 - ¥36.5 - 10月8日
   → 完成评价可获：XX优惠券

2. [已评价] 麦辣鸡腿堡 - ¥22.5 - 10月5日
   → 奖励券：XX优惠券（未使用，到期日XX）
```

### 2. 评价奖励券管理

对已评价的订单，调用 `query-survey-coupon` 获取奖券详情，统一管理所有评价奖励券：

- 奖券名称
- 核销状态（已核销/未核销）
- 核销时间
- 适用场景（到店/外送）
- 到期提醒

如果有即将到期的评价奖励券，醒目提醒用户："您有X张评价奖励券即将过期，请尽快使用！"

### 3. 评价引导

引导用户完成评价：
1. 展示待评价订单列表
2. 用户选择某笔订单
3. 询问评价维度：餐品口味/配送速度/服务态度/整体满意度
4. 记录用户反馈
5. 告知预期奖励内容
6. 引导用户去麦当劳APP完成正式评价（正式问卷需在APP内提交）

### 4. 价值统计

汇总展示评价带来的价值：
- 累计完成评价数
- 累计获得奖励券数
- 奖励券总价值估算
- 未使用的奖励券价值（"你还有¥XX的奖励券没用！"）

## Workflow

```
用户想评价/查评价奖励
    │
    ├─ order-list → 获取历史订单
    │     └─ query-survey-coupon(逐条) → 查询每笔的问卷状态
    │
    ├─ 分类展示 → 待评价/已评价未核销/已核销/已过期
    │
    ├─ 待评价 → 引导完成评价 → 告知奖励
    │
    ├─ 未核销奖励券 → 提醒使用 + 到期提醒
    │
    └─ 价值统计 → 累计评价价值报告
```

## Important Rules

- `query-survey-coupon` 需要 orderId，来自 `order-list` 返回结果，不可自行编造
- 正式问卷提交需在麦当劳APP内完成，本技能负责发现和引导，不替代正式提交
- 展示奖券信息时只展示返回的字段（满意度描述、奖券标题、核销时间、核销状态、点餐方式），不猜测未返回的字段
- 到期券必须醒目提醒
- 如果所有订单都已评价或已过期，告知用户"暂无可评价订单，下次消费后再来吧"
