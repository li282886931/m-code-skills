# Mcd Deal Hunter — 麦当劳省钱达人

## Overview

综合运用 mcd-mcp 的优惠券、促销、价格计算等工具，自动为用户找到麦当劳点餐的最低成本方案。覆盖领券、比价、满减计算、套餐拆解等全链路省钱策略。

## Core Capabilities

### 1. 一键领券

调用 `auto-bind-coupons` 自动领取所有当前可用的麦当劳优惠券。调用后展示领取结果（成功几张、失败原因）。

调用 `available-coupons` 查看当前可领取但尚未领取的券，展示券名称、优惠力度、使用条件。

### 2. 门店可用券查询

用户确定门店后，调用 `query-store-coupons` 查询该门店当前可用的优惠券列表。展示每张券的：
- 券名称
- 优惠金额/折扣
- 适用商品/分类
- 使用条件（满额、时段等）
- 到期时间

### 3. 最优价格计算

用户选定商品后，调用 `calculate-price` 计算价格。核心省钱逻辑：

1. **优惠券最优匹配**：遍历用户卡包中的券(`query-my-coupons`) + 门店可用券(`query-store-coupons`)，对每张券调用 `calculate-price` 传入 couponId/couponCode，比较得出最低价
2. **套餐vs单品对比**：对同一组餐品，分别以"套餐购买"和"单品分开购买"计算价格，取更低者
3. **随单购优惠**：检查 `query-meals` 返回的 `canWithOrder=true` 的商品，随单购麦金卡可享受额外折扣
4. **满减叠加**：团餐场景调用 `query-promotions` 获取满减/满折规则，按规则搭配合以达到满减门槛

### 4. 预算内最大化

用户给出预算（如"30元以内"）后：
1. 调用 `query-meals` 获取菜单及价格
2. 按性价比（克数/价格或热量/价格）排序
3. 用贪心算法在预算内选择商品组合
4. 同时检查是否有适用的优惠券可进一步降低成本
5. 输出方案：商品列表、原价、优惠后价格、节省金额

### 5. 促销活动分析

团餐场景(beType=6)下，调用 `query-promotions` 获取满减/满折规则，解读并展示：
- 满XX减YY
- 满XX折YY折
- 适用商品范围
- 活动时间

帮助用户合理搭配以达到满减门槛。

## Workflow

```
用户想省钱点餐
    │
    ├─ 一键领券 → auto-bind-coupons → 展示领取结果
    │
    ├─ 查门店券 → query-store-coupons → 展示可用券列表
    │
    ├─ 最优价格 → calculate-price（遍历券组合）→ 输出最低价方案
    │
    ├─ 预算内最大化 → query-meals → 贪心搜索 + 券优化 → 输出方案
    │
    └─ 促销分析 → query-promotions → 解读满减规则 → 搭配建议
```

## Important Rules

- 价格计算结果单位为"分"，展示时除以100转为"元"
- 优惠券匹配需考虑使用条件（满额、适用商品、时段），不满足条件的券不参与比较
- `query-my-coupons` 返回的券不保证可用于当前门店/订单，需用 `query-store-coupons` 确认可用性
- 随单购商品(`canWithOrder=true`)需在 `calculate-price` 的 `withOrder` 参数中传入，才能享受优惠
- 每次推荐方案时，同时展示"原价"和"优惠后价格"，让用户直观看到节省金额
- 如果有多张券可用但互斥（不可叠加），分别计算每张券的最终价格取最低
