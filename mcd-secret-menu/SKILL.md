# Mcd Secret Menu — 麦当劳隐藏菜单探索

## Overview

麦当劳的每个汉堡、每个套餐都可以"特调"——加芝士、去酸黄瓜、换酱料、套餐换饮料。但这些定制选项藏在 `query-meal-detail` 的 modification 数据里，大多数用户从不知道。本技能挖掘所有餐品的特调能力，组合出有趣的"隐藏菜单"，像 In-N-Out 的 Secret Menu 一样让用户发现麦当劳不为人知的玩法。

## Core Capabilities

### 1. 特调能力全景扫描

调用 `query-meals` 获取全量菜单，对每个餐品调用 `query-meal-detail` 检查 `supportModify` 字段，扫描所有可特调的餐品，建立特调能力索引：

- 哪些汉堡可以加芝士/加倍肉/去酱
- 哪些套餐的子项可以互换（如把可乐换成咖啡）
- 哪些小食可以加蘸酱/换口味
- 哪些饮品可以调整甜度/加料

展示格式：
```
🔓 隐藏菜单探索

🍔 汉堡特调
- 巨无霸 → 【可特调】加芝士/加倍肉饼/去酸黄瓜/换酱
- 麦辣鸡腿堡 → 【可特调】去辣酱/加生菜/加倍鸡肉

🍟 小食特调
- 薯条 → 【可特调】加盐/不加盐
- 蘸酱炸鸡 → 【可特调】换韩式芝士酱/换日式山葵酱

🥤 饮品特调
- 浓缩咖啡 → 【可特调】加燕麦奶/调整浓度

📦 套餐换子项
- 巨无霸三件套 → 饮料可换/薯条可换玉米杯/可加小食
```

### 2. 隐藏搭配组合

基于特调能力，设计有趣的"隐藏搭配"：

**经典隐藏菜单**：
- **巨无霸肉食者版**：加倍肉饼 + 加芝士 + 去酸黄瓜 → 纯粹的肉食狂欢
- **减脂版麦辣鸡腿堡**：去辣酱 + 去鸡皮(如支持) → 热量直降
- **甜品咖啡**：浓缩咖啡 + 加燕麦奶 + 加糖浆 → 隐藏版燕麦拿铁
- **酱多多薯条**：薯条 + 加盐 + 额外蘸酱 → 蘸酱自由

**创意组合**：
- **早餐汉堡**：巨无霸 + 换早餐酱 → 罕见的早餐风味
- **芝士控天堂**：任意汉堡 + 加芝士 + 配马苏里拉拉丝芝士条
- **酱料探索者**：蘸酱炸鸡 + 每种酱各一份 → 尝遍所有风味

### 3. 特调订单生成

用户选定特调方案后，调用 `query-meal-detail` 获取 modification 的完整参数：
1. 获取 `selectedKey`（选中项的 key）
2. 获取 `unselectedKey`（未选中项的 key，不为空时也必须传入）
3. 组装 modification.values 数组，包含所有特调组内的选项
4. 调用 `calculate-price` 计算特调后价格
5. 调用 `create-order` 下单，items 中传入 modification 参数

### 4. 价格影响分析

特调可能影响价格（加芝士加钱、去配料不退钱等），调用 `calculate-price` 对比特调前后的价格：
- 原价 vs 特调后价格
- 差额说明（加料加费/换项不加费/去料不退费）
- 建议是否值得特调

### 5. 口味实验推荐

基于特调能力，推荐用户尝试"口味实验"：
- 从未尝试过的酱料组合
- 不同汉堡换不同酱的搭配
- 饮品+小食的混搭蘸法（如薯条蘸麦旋风——经典隐藏吃法）

## Workflow

```
用户想探索隐藏菜单
    │
    ├─ 全景扫描 → query-meals → 逐个 query-meal-detail → 建立特调索引
    │
    ├─ 隐藏搭配展示 → 展示经典隐藏菜单 + 创意组合
    │
    ├─ 用户选定方案 → query-meal-detail → 获取 modification 参数
    │                    └─ selectedKey + unselectedKey 组装
    │
    ├─ 价格对比 → calculate-price(原版) vs calculate-price(特调版)
    │
    └─ 下单 → create-order(含 modification) → 引导支付
```

## Important Rules

- 特调参数组装规则：对于包含 `unselectedKey` 的特调组，该组内**所有**特调项都必须传入，选中的用 `selectedKey`，未选中的用 `unselectedKey`
- 不可主动展开特调选项列表，仅当用户主动询问时才展示 modification 内容
- 特调可能改变价格，必须先调用 `calculate-price` 确认价格后再下单
- 套餐子项更换通过 `roundList` 参数传入，不是 modification
- 不是所有餐品都支持特调，需检查 `supportModify=true`
- 隐藏搭配仅为推荐，实际可用特调项以 `query-meal-detail` 返回为准
- 口味实验推荐需有趣味性，但不推荐明显不合理的组合
